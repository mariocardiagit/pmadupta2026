AJOUT DE SCROLLBARS SUR TOUS LES GRAPHIQUES

Version : 04/08/2026

Modifications appliquées :

1. Tous les graphiques Canvas présents dans le fichier HTML reçoivent :
   - une scrollbar horizontale ;
   - une scrollbar verticale.

2. Les graphiques qui possédaient déjà une zone défilable conservent leur
   structure existante :
   - graphiques chronologiques de l’onglet 2 ;
   - graphiques des réalisations ;
   - diagrammes de périodes Gantt ;
   - graphiques en affichage individuel.

3. Les autres graphiques sont automatiquement placés dans un conteneur
   défilable avec une scène intérieure agrandie, notamment :
   - K-Means ;
   - Jenks ;
   - DBSCAN ;
   - analyse avancée ;
   - clustering sémantique ;
   - graphiques créés dynamiquement.

4. Un MutationObserver détecte les nouveaux Canvas ajoutés après le chargement
   et leur applique automatiquement les deux scrollbars.

5. Les graphiques sont redimensionnés après :
   - l’ajout du conteneur défilable ;
   - le changement d’onglet ;
   - la création dynamique d’un graphique.

6. Les scrollbars sont stylisées pour Chromium/Edge/Safari et Firefox.
