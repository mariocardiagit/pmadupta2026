MISE À JOUR — ANALYSE DES RÉALISATIONS DES STD, VERSION 2
==========================================================

Cette version complète l’onglet « Analyse des Réalisations des STD (DREN, CISCO, ZAP) ».

1. Types de graphiques ajoutés
--------------------------------
- Courbes
- Courbes lissées
- Courbes en escalier
- Aires
- Barres verticales
- Barres verticales empilées
- Barres horizontales
- Barres horizontales empilées
- Histogramme
- Graphique mixte : barres et courbes
- Radar
- Nuage de points
- Diagramme circulaire
- Diagramme en anneau
- Aires polaires

Les courbes utilisent également des pointillés et des formes de points différentes afin de mieux distinguer les séries qui se superposent.

2. Zoom temporel
-----------------
Deux boutons ont été ajoutés :
- Zoom + : passe vers une granularité plus détaillée, par exemple Mois → Semaine → Jour.
- Zoom - : passe vers une granularité plus agrégée, par exemple Mois → Trimestre → Semestre → Année.

3. Organisation des graphiques
-------------------------------
- Affichage groupé : toutes les entités d’un niveau sont réunies dans un même graphique.
- Affichage individuel : un graphique séparé est généré pour chaque DREN, CISCO ou ZAP.

En affichage individuel, le bouton d’export produit une archive ZIP lorsqu’il existe plusieurs graphiques.

4. Correspondance des filtres de dates
---------------------------------------
- « Date de début — OM missionnaire » filtre directement le champ Kobo « Date debut realisation dans om missionnaire ».
- « Date de fin — OM missionnaire » filtre directement le champ Kobo « Date fin realisation dans om missionnaire ».

La date choisie dans « Date utilisée sur l’axe temporel » sert uniquement à positionner les valeurs sur l’axe horizontal. Elle ne remplace plus les deux champs de recherche OM missionnaire.

5. Type de données
------------------
La liste « Type de données » conserve :
- Données détaillées
- Données cumulées
