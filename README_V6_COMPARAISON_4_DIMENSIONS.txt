V6 — COMPARAISON AVANCÉE DES RÉALISATIONS : 4 DIMENSIONS

Ajout dans chacun des quatre niveaux DREN / CISCO / ZAP / STD de quatre sous-onglets :
- Activité
- Produit
- Sous Activité (sélection par défaut pour conserver le comportement précédent)
- Sous Produit

Chaque changement de dimension recalcule :
- la liste de valeurs comparables ;
- la cartographie des réalisations proches ;
- les groupes proches ;
- le diagramme des périodes ;
- les indicateurs ;
- le tableau d'audit ;
- l'interprétation intelligente.

La logique de connexion KoboToolbox de la V5 est conservée sans modification.
