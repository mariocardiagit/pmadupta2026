AJOUT DES EXPORTS EXCEL XLSX — ANALYSE DES RÉALISATIONS DES STD

Boutons ajoutés :
- Excel XLSX global : DREN + CISCO + ZAP ;
- Excel XLSX DREN ;
- Excel XLSX CISCO ;
- Excel XLSX ZAP.

Chaque classeur contient :
1. Feuille « Synthèse » : nombre de réalisations, entités actives, valeur totale et période couverte.
2. Feuille « Critères » : type de graphique, rôle du graphique, graduation temporelle,
   données détaillées/cumulées, organisation, Top entités, dates OM minimales/maximales.
3. Feuille(s) « Données DREN/CISCO/ZAP » :
   - ID Kobo ;
   - niveau ;
   - entité ;
   - sous-activité ;
   - date début réalisation OM ;
   - date fin réalisation OM ;
   - durée inclusive calculée par une formule Excel ;
   - valeur de réalisation ;
   - date de suivi ;
   - date de soumission ;
   - statut de liaison.
4. Feuille(s) « Graphique » : image PNG haute définition du ou des graphiques actuellement affichés.

Les données exportées respectent les bornes de dates OM, le Top d’entités et le niveau sélectionné.
