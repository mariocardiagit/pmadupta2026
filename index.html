    Explicabilité (XAI) : Détails et Démonstrations Mathématiques

    Pourquoi utiliser ces algorithmes ?

    Le regroupement des données ne peut pas se fier à des seuils humains arbitraires. La vraie Intelligence Artificielle écoute la structure intrinsèque de la donnée. Nous combinons des philosophies mathématiques différentes pour assurer une objectivité totale.

    Algorithme 1 : K-Means (Centre de Gravité)

    Le K-Means est un algorithme de partitionnement géométrique. Son but est de regrouper $N$ observations en $K$ clusters en minimisant l'inertie intra-classe.

    Démonstration Mathématique :

    Imaginons 5 ZAP ayant respectivement soumis : X = { 2, 3, 10, 12, 25 } formulaires. L'IA cherche à les diviser en K=3 groupes.

    Étape 1 : Initialisation des centres de gravité moyens. Supposons μ1 = 2.5 (Faible), μ2 = 11 (Moyen), μ3 = 25 (Fort).
    Étape 2 : Assignation des ZAP aux centres les plus proches.
    Étape 3 : L'algorithme calcule son score d'erreur (Inertie J).

    L'algorithme tourne jusqu'à trouver le "J" minimum absolu.

    Algorithme 2 : Jenks (Natural Breaks)

    Conçu spécifiquement pour les données unidimensionnelles (1D), c'est l'algorithme le plus précis pour cette plateforme. Il procède de manière déterministe pour trouver les "ruptures" optimales en cherchant à maximiser le critère GVF.

    GVF = ( SDTM - SDIC ) / SDTM
    Algorithme 3 : DBSCAN (Détection Anomalies)

    DBSCAN ne force pas la répartition des données dans 3 groupes prédéfinis. Il "scanne" la liste pour trouver les zones où les entités sont très concentrées, et isole celles qui sont mathématiquement trop éloignées (Bruit / Anomalie).

    Onglet 11 : Explicabilité (XAI) de la Détection des Doublons

    Quel est le but de cette vérification ?

    Cet algorithme a été conçu pour repérer automatiquement les erreurs de saisie ou les répétitions anormales dans KoboToolbox. Il ne sanctionne pas une ZAP qui réalise plusieurs activités différentes, mais il alerte immédiatement si une ZAP soumet exactement la même activité plusieurs fois par le même agent (même Matricule).

    Module d'Analyse Quantitative des Réalisations

    Ce module se concentre exclusivement sur les champs chiffrés de type "Réalisation" (quantités, montants, effectifs réalisés sur le terrain) pour comparer mathématiquement et temporellement les performances des DREN, CISCO et ZAP.
    Règle stricte appliquée : L'attribution se fait sans aucun cumul hiérarchique. Une réalisation appartient exclusivement à son auteur direct.

    Comparaison Temporelle des Réalisations Cumulées
    Le graphique ci-dessous additionne toutes les valeurs chiffrées trouvées dans la colonne "Réalisation" (ou "Quantité", "Nombre") pour chaque entité au fil du temps.

    Cliquez sur le bouton "Lancer l'Analyse Temporelle" pour générer le graphique.
    IA : Classification des Performances Quantitatives Globales

    L'algorithme de Jenks évaluera le volume total cumulé des réalisations réelles de chaque entité afin d'identifier mathématiquement les entités les plus performantes et celles en difficulté sur le terrain.
