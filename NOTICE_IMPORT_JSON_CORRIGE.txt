Correction du bouton « Importer manuellement la base Kobo (Fichier JSON) ».

Constat :
- Le champ de fichier principal #json-file était visible, mais aucun gestionnaire d’événement n’était relié à ce champ dans la version précédente.
- Le nom du fichier pouvait donc apparaître dans le navigateur sans que son contenu soit effectivement chargé.
- Le badge « Ok : … lignes » pouvait provenir de la connexion automatique KoboToolbox et ne prouvait pas l’import manuel.

Correction :
- ajout du gestionnaire de changement pour #json-file ;
- lecture UTF-8 du fichier ;
- suppression éventuelle du marqueur BOM ;
- analyse JSON avec messages d’erreur explicites ;
- formats acceptés : tableau direct ou objets contenant results, data, records, rows ou base_kobo ;
- validation des lignes ;
- remplacement de la base active ;
- actualisation du tableau principal, de l’analyse, des graphiques et du module avancé ;
- badge de confirmation « JSON chargé : N ligne(s) » avec le nom du fichier.

Test attendu :
Après sélection d’un fichier valide, le badge doit afficher « JSON chargé : N ligne(s) » et non seulement « Ok : N Lignes ».
