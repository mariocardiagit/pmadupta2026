1. Inspiration DATA MUST SPEAK

Le module reprend la logique du classeur et ajoute trois onglets territoriaux DREN / CISCO / ZAP : centre d’accueil, tableaux de bord, questions utiles, recherche et détails graphiques.

2. Données KoboToolbox

Les assets CISCO et ZAP identifiés dans le classeur peuvent être synchronisés directement via l’API KoboToolbox. Un import JSON reste disponible en secours.

3. Restitution dynamique

Chaque question peut être analysée globalement ou, lorsque les données détaillées sont chargées, regroupée par DREN, CISCO ou ZAP, avec graphique et tableau des valeurs exactes.

4. Confidentialité

Le snapshot livré avec le site est agrégé. Les valeurs NOM, PRÉNOMS, TÉLÉPHONE et les textes libres individuels ne sont pas intégrés dans le code public.
